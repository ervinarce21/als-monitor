# ALS Monitor

Raspberry Pi project scaffold for the ALS monitoring device.

## Project structure

- `src/als_monitor/` - application source
- `config/` - configuration files
- `hardware/` - hardware notes and interfaces
- `data/` - local runtime data (ignored by Git)
- `scripts/` - setup and maintenance scripts
- `docs/` - project documentation
- `tests/` - automated tests

Local databases, secrets, virtual environments, recordings, and generated Python files are excluded from version control.
